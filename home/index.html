Macintosh PiForma NEW!

A Raspberry Pi Macintosh Performa fever dream built inside an Apple IIc Monitor.
The old CRT was toast, so I kept the case and rebuilt the guts: a Raspberry Pi 4B, an LCD, a battery, a boot chime, a tap-able Apple logo button and a Bluetooth-converted ADB keyboard. It even travels in a velvet-lined bag. Puns are allowed here.
  • Take the Guided Tour
    The whole build, served up in a HyperCard-style stack.
  • The Build Docs
    Everything: hardware, wiring, power rail, software, and STL files.
  • The Owner's Guide (PDF)
    A full 80s-style Apple owner's manual for a computer Apple never made.
